Choose either installation option for Windows 10 or Windows 11:

- **[Microsoft Store](https://apps.microsoft.com/detail/xpfpjch810mwl0)** - install VisoDyne Battery Monitor from its Windows Store listing.
- **[Classic setup installer](https://download.visodyne.com/v1/batterymonitor/setup)** - download the Windows installer directly from VisoDyne.

Both versions include the **free Community edition** and a **free trial of Pro features**. The same VisoDyne Pro license key works with both versions.

## Wireless Battery Monitoring Features

- **Battery percentage in the Windows system tray:** see the charge of supported Bluetooth, 2.4 GHz, and proprietary wireless devices without opening a vendor utility.
- **AirPods battery on Windows:** view separate left earbud, right earbud, and charging case levels when reported by the device.
- **Wireless headset, mouse, keyboard, and controller monitoring:** keep battery information together in one app.
- **Low-battery notifications:** get default alerts in Community, or customize normal and urgent warnings with Pro.
- **Customizable tray icons:** choose device visibility, with additional icon styles and battery-color thresholds in Pro.
- **Estimated battery time:** get remaining-time estimates for devices that report charge in coarse steps.
- **Background operation:** keep monitoring from the tray, with optional launch at Windows startup.

Feature availability depends on the edition and the battery information supplied by each device. See [Community vs. Pro](#free-community-edition-and-pro) below.

## How to Install

### Microsoft Store

1. Open the [VisoDyne Battery Monitor Microsoft Store listing](https://apps.microsoft.com/detail/xpfpjch810mwl0).
2. Install the app, then launch **VisoDyne Battery Monitor** from the Start menu.
3. Connect your wireless devices and check their battery levels in the app.

### Classic Windows Setup

1. [Download the classic setup installer](https://download.visodyne.com/v1/batterymonitor/setup).
2. Run the installer and approve the administrator prompt.
3. Launch **VisoDyne Battery Monitor** from the Start menu or desktop shortcut.
4. Connect your wireless devices and choose which device to show in the system tray.

### WinGet

You can also install from Windows Terminal or PowerShell:

```powershell
winget install --id VisoDyne.BatteryMonitor
```

## Free Community Edition and Pro

The **Community edition is free and never expires**: no account and no time limit. It detects and shows every supported device in the app window, with one device in the system tray and default low-battery alerts. You can switch the tray icon to another device at any time.

**Pro** adds tray icons for unlimited devices, custom icon styles, custom battery colors, custom notification rules, and faster refresh intervals. Pro is a **one-time purchase, not a subscription**. A free trial lets you try the paid features before buying.

See the [official product page for current Pro features and licensing](https://visodyne.com/en/battery-monitor).

## Frequently Asked Questions

### How do I check AirPods battery levels on Windows?

Install VisoDyne Battery Monitor, connect your AirPods via Bluetooth, and open the app. Supported AirPods report separate left earbud, right earbud, and case battery levels. Readings depend on what the device is currently reporting.

### Can I see my wireless mouse, headset, or controller battery in the taskbar?

Yes, supported devices can show their battery level in the Windows system tray, also called the taskbar notification area. Community shows one device there; Pro adds a tray icon for each device.

### Does it work with 2.4 GHz USB receivers as well as Bluetooth?

Yes. The app supports Bluetooth battery reporting and supported 2.4 GHz or proprietary wireless receivers. Compatibility depends on the device and receiver, not just the brand. See the [supported-device catalog](https://visodyne.com/en/battery-monitor/supported-devices) for receiver-specific notes.

### What if my device is not listed or its battery is missing?

The list is not exhaustive, and device support is continually updated. You can help in two ways:

- Enable **Share usage data to help improve the app** in **Settings > About**. These periodic device and battery diagnostics help us find devices the app detects but cannot read reliably yet.
- Use the **Feedback** button in the app's title bar and choose the **Device Support** category to report a missing or misreported device, including its model and connection type.
